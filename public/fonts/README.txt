A.I.D.A brand typeface
======================

The brand name "A.I.D.A" is set in  Prestige Elite M Bold  (URW Type Foundry) wherever it appears
in the interface (see src/theme/brand.css).

Prestige Elite M is a licensed font and is NOT bundled. To switch it on:

  1. Licence it, then convert the Bold to WOFF2.
  2. Save the file here as:   public/fonts/PrestigeEliteM-Bold.woff2
  3. Rebuild / redeploy. No code change is needed.

Until that file exists the brand name falls back to Courier Prime Bold (CourierPrime-Bold.woff2,
SIL Open Font License, see CourierPrime-OFL.txt), a free typewriter face in the same spirit.
